Quick setup

Bring your bot online.

Configure your private storage channel and environment before starting the Python bot.

01 — Create a private storage channel

  • Create a private Telegram channel to use as your vault.
  • Add your bot as an administrator with permission to post messages.
  • Copy the channel ID (usually starts with -100).

02 — Configure environment

BOT_TOKEN=your_bot_token OWNER_ID=your_telegram_user_id ADMIN_IDS= STORAGE_CHANNEL_ID=-1001234567890 BACKUP_EVERY_HOURS=1 USE_CUSTOM_EMOJI=1

Keep your .env file private. Never publish your bot token or share it in screenshots.

03 — Install and run

pip install -r requirements.txt python filestore_bot.py

Good to know

Frequently asked questions.

Can the bot store more than one file per link?

Yes. Admins can upload multiple files, tap Done, and receive one link for the complete batch.

How does join-to-unlock work?

When a visitor opens a link, the bot checks membership in the required chats. If they have joined, they can verify and receive the files.

Does content protection prevent every kind of copying?

No. Telegram's protected-content setting can restrict forwarding and saving in supported clients, but it cannot prevent every possible capture (for example, photographing a screen with another device).

Why might membership verification fail?

The bot generally needs administrator access in each required channel or group so Telegram allows it to check membership. Also verify that the chat ID or username is correct.
